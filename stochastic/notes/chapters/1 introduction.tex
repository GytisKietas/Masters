\section{Introduction}

What is a model (modelling)? 

\begin{equation*}
    \text{Phenomenon}  \rightarrow  \text{Mathematical Problem}  \rightarrow  \text{Mathematical solution}  \rightarrow  \text{Interpretation}  \rightarrow  \text{Phenomenon} \dots
\end{equation*}

\noindent
There are several objectives of simulations:
\begin{itemize}
    \item Fitting the model, determining optimal paramters
    \item Determining the state of the system
    \item Numerical experiment, analysis and predictions
    \item Inverse problem: determining the system initial conditions
\end{itemize}

\noindent
Models are classified into
\begin{itemize}
    \item Discrete
    \item Continuous
\end{itemize}

\noindent
They are further classified into:
\begin{itemize}
    \item Deterministic
    \item Stochastic
    \item Heuristic (Genetic algorithms, Neural networks, Simulated annealing)
\end{itemize}

\noindent
And they can be Detailed of Phenomenological.
